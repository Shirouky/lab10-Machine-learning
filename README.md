# Лабораторная работа №10: Классификация изображений CIFAR-10 с использованием классических методов машинного обучения

## Описание
В работе решается задача классификации изображений из набора данных CIFAR-10 (10 классов: самолёт, автомобиль, птица, кошка, олень, собака, лягушка, лошадь, корабль, грузовик). Изображения имеют низкое разрешение (32×32 пикселя, RGB). Выполнена предобработка: перевод в оттенки серого, извлечение признаков HOG (гистограммы ориентированных градиентов) и LBP (локальные бинарные паттерны). Признаки масштабированы. Обучены две модели: Random Forest и SGDClassifier (линейный SVM) на каждом типе признаков. Проведён подбор гиперпараметров (n_estimators для RF, alpha и penalty для SGD) на валидационной выборке. Лучшая модель – SGD с HOG-признаками показала Accuracy ≈ 46.5% и F1-macro ≈ 0.47. Проведён анализ ошибок с визуализацией матрицы ошибок и примеров правильных и неправильных предсказаний.

## Функциональность

### 1. Загрузка и изучение данных
- Датасет CIFAR-10 загружается с помощью `tensorflow_datasets`.
- Визуализированы примеры изображений из каждого класса.
- Данные разделены на обучающую (50000) и тестовую (10000) выборки.

### 2. Предобработка и извлечение признаков
- Изображения нормализованы (деление на 255).
- Перевод в оттенки серого для упрощения.
- Извлечение признаков:
  - **HOG** (Histogram of Oriented Gradients): параметры (orientations=9, pixels_per_cell=(4,4), cells_per_block=(2,2)). Размерность: 1764.
  - **LBP** (Local Binary Patterns): радиус 2, 8 точек, гистограмма унифицированных паттернов. Размерность: 10.
- Признаки масштабируются с помощью `StandardScaler`.

### 3. Разделение выборки
- Обучающая выборка разбивается на тренировочную (80%) и валидационную (20%) с сохранением стратификации.
- Для ускорения экспериментов используется подвыборка из 10000 примеров для обучения моделей (валидация выполняется на всех данных).

### 4. Обучение моделей
- **Random Forest**:
  - Подбор `n_estimators` из {20, 30, 50, 80} на HOG-признаках, выбрано 80.
  - Обучение на всех трёх типах признаков.
- **SGDClassifier** (линейный SVM с loss='hinge'):
  - Подбор `alpha` (0.0001, 0.001) и `penalty` (l1, l2) на HOG-признаках, лучшие параметры: alpha=0.001, penalty='l2'.
  - Обучение на всех трёх типах признаков.

### 5. Оценка и анализ
- Все модели оценены на тестовой выборке по Accuracy, Recall-macro и F1-macro.
- Построена матрица ошибок для лучшей модели (SGD с HOG).
- Визуализированы примеры правильных и ошибочных предсказаний.
- Выявлены наиболее частые путаницы (например, dog ↔ cat, dog ↔ bird).

## Результаты

### Тестовые метрики (на 10000 изображений)

| Модель          | Accuracy | Recall-macro | F1-macro |
|-----------------|----------|--------------|----------|
| RF (pixels)     | 0.4168   | 0.4168       | 0.4141   |
| RF (HOG)        | 0.3755   | 0.3755       | 0.3722   |
| RF (LBP)        | 0.2670   | 0.2670       | 0.2638   |
| SGD (pixels)    | 0.3659   | 0.3659       | 0.3691   |
| **SGD (HOG)**   | **0.4648**| **0.4648**   | **0.4684** |
| SGD (LBP)       | 0.1394   | 0.1394       | 0.1077   |

**Лучшая модель** – SGDClassifier с HOG-признаками: Accuracy ≈ 46.5%, F1-macro ≈ 0.47.

### Анализ ошибок
Наиболее частые ошибки (для SGD с HOG):
- dog → cat (239)
- dog → bird (173)
- airplane → bird (147)
- automobile → truck (144)
- cat → bird (136)

Это объясняется визуальной схожестью классов (например, собаки и кошки, самолёты и птицы).

## Выводы
- HOG-признаки оказались наиболее информативными среди рассмотренных, дав лучший результат.
- Линейный SVM (SGDClassifier) превзошёл Random Forest на HOG-признаках, вероятно, благодаря лучшему разделению в пространстве признаков.
- LBP-признаки показали низкую эффективность, что может быть связано с малым размером изображений (32×32) и недостаточной текстурной информацией.
- Общая точность (~46%) далека от современных нейросетевых подходов (>90%), что ожидаемо для классических методов на таком сложном наборе данных.
- Анализ ошибок указывает на сложность различения визуально похожих классов, что требует более сложных признаков или глубокого обучения.
